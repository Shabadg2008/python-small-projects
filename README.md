# Python Small Projects

A collection of beginner-friendly Python projects and scripts I built while learning computer science fundamentals.

## Projects Included

* **Password Generator** - A utility script that generates secure, randomized passwords based on user-defined length and character preferences.
* **Quiz** - An interactive command-line trivia game that tests users on various topics and tracks their score.
* **Simple Calculator** - A functional calculator handling basic arithmetic operations with user input validation.
* **To-Do List** - A task management tool allowing users to add, view, and organize their daily tasks.
* **Number Guessing Game** - An interactive game where the user tries to guess a randomly generated number within a set range with hint prompts.
* **Rock Paper Scissors** - A terminal-based classic game implementing game logic against a computer opponent.
* **Time Clock** - A alarm program that shows a live countdown in the terminal. (Seconds)
* **Countdown** - Enter a date (mm/dd/yr) and the terminal will show how many years, months, days, hours, minutes, and seconds are left.
* **Weather Fetcher** - A Python program that fetches real-time temperature, wind speed, and weather conditions for any city based on user input using the OpenWeatherMap API
